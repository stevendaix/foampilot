# Tobias — Magnus Effect

## Identification and objective

This directory ports Tobias Holzmann’s **Magnus Effect** training case, a 2-D cylinder mesh and incompressible flow calculation investigating the lift generated by a rotating cylinder. The official OpenFOAM 12 archive was recovered at `OpenFOAMCases/014_magnusEffect/magnusEffect-12.tar.gz` after the Tobias web page returned a temporary HTTP 500 error.

## FoamPilot implementation

`run.py` generates the text case files through `OpenFOAMDictAddFile.write_raw`, copies the supplied `backgroundMesh.unv` and `cylinder.stl` assets, and launches the full source sequence through FoamPilot: `ideasUnvToFoam`, `snappyHexMesh`, `extrudeMesh`, `changeDictionary`, `transformPoints`, and `foamRun -solver incompressibleFluid`. The original shell runner is not executed.

The OpenFOAM 12 `linearNormalCoeffs` dictionary contained only `thickness`. OpenFOAM 13 requires `nLayers` and `expansionRatio` in that subdictionary, so the runner adds those two required entries. The STL path is also written relative to the generated `constant/triSurface` directory. The source `endTime` of 40 s is shortened to 0.2 s for bounded validation; this is not claimed as the full production run.

The case is **validated: short calculation run**. The generated mesh and solver both completed under OpenFOAM Foundation 13 through FoamPilot.
