# Checklist Pré-Publication — Article Hebdomadaire

**À compléter avant chaque publication Medium.**

---

## 📝 Rédaction

- [ ] Article rédigé selon le template (`template.md`)
- [ ] Titre validé (< 70 caractères, accrocheur)
- [ ] Introduction qui capte l'attention en 2 phrases
- [ ] Un seul concept principal par section
- [ ] Transition logique entre chaque section
- [ ] Conclusion avec CTA clair
- [ ] Longueur entre 1200 et 1800 mots

---

## 💻 Code et technique

- [ ] Tous les exemples de code ont été exécutés et testés
- [ ] Code formaté (4 espaces, pas de tabulations)
- [ ] Blocs de code avec langage `python` spécifié
- [ ] Commentaires explicatifs dans le code
- [ ] Pas de secrets / clés API / credentials dans le code
- [ ] Liens vers le repo GitHub vérifiés (pas de liens cassés)
- [ ] Chemins de fichiers relatifs corrects

---

## 🖼️ Visuels

- [ ] Image d'en-tête ajoutée (ratio 16:9, < 500 KB)
- [ ] Schémas annotés si nécessaire
- [ ] Captures d'écran avec flèches/numéros si nécessaire
- [ ] Légendes sous chaque image
- [ ] Visuels optimisés pour mobile

---

## 📖 Révision éditoriale

- [ ] Relecture orthographique (français)
- [ ] Pas de fautes de grammaire
- [ ] Ton professionnel mais accessible
- [ ] Jargon expliqué à sa première occurrence
- [ ] Pas de "je" excessif → "on" / "nous" / impersonnel
- [ ] Pas de tutoiement
- [ ] Pas de contenu promotionnel excessif
- [ ] Citations et références vérifiées

---

## 🚀 Publication Medium

- [ ] Article copié-collé dans l'éditeur Medium
- [ ] Formatage Markdown correctement interprété
- [ ] Images insérées au bon endroit
- [ ] Tags Medium ajoutés (3-5 tags pertinents)
- [ ] Publication programmée ou immédiate
- [ ] Canonical URL vérifiée (si cross-posting)

---

## 📢 Diffusion

- [ ] Publication sur Twitter/LinkedIn avec extrait accrocheur
- [ ] Partage dans les communautés pertinentes (Reddit r/CFD, r/Python, etc.)
- [ ] Notification dans le repo GitHub (release, pinned post)
- [ ] Mise à jour du calendrier éditorial (`calendar.md`)
- [ ] Archiver l'article publié dans `articles/published/`

---

## 📊 Suivi post-publication

- [ ] Répondre aux commentaires dans les 24h
- [ ] Noter les statistiques (vues, claps, commentaires)
- [ ] Identifier les questions récurrentes → sujets futurs
- [ ] Mettre à jour le planning si un sujet performe bien

---

## Métriques de succès (par article)

| Métrique | Seuil de validation |
|----------|---------------------|
| Vues à J+7 | > 500 |
| Claps | > 50 |
| Commentaires | > 3 |
| Taux de lecture complète | > 40% |
| Partages | > 5 |
